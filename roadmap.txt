FINANCE-INDEX DASHBOARD — ROADMAP (GENERALIST → NICHE)

=================================================================
🌱 PHASE 1 — GENERALIST TRANSPARENT INDEX SANDBOX
=================================================================
Goal: Learn weighting, scoring, and index-level math through simple, auditable factor indices.

-----------------------------------------------------------------
1️⃣ Purpose
-----------------------------------------------------------------
Build a transparent, reproducible framework for constructing and explaining factor-based indices. 
Everything — signals, ranks, weights, and levels — must be traceable to raw data.

-----------------------------------------------------------------
2️⃣ Scope
-----------------------------------------------------------------
- Universe: S&P 500 + NASDAQ 100 (≈ 600 names)
- Data sources: yfinance (prices/dividends), local signals table
- Output: daily index levels + weight logs + narrative summaries

-----------------------------------------------------------------
3️⃣ Indices to implement
-----------------------------------------------------------------
Slug           | Theme          | Selection                     | Weighting
---------------|----------------|--------------------------------|------------
momentum-10    | Momentum       | Top 10 by 6-month return       | Equal
value-25       | Value          | Top 25 by Earnings Yield (1/P E) | Equal
quality-25     | Quality        | Top 25 by ROE                  | Equal
lowvol-25      | Low Volatility | Lowest 25 by 60-day σ          | Equal
composite-50   | Multi-factor   | Blend of Momentum + Value + Quality | Score-weighted

-----------------------------------------------------------------
4️⃣ Core data & signals
-----------------------------------------------------------------
Category   | Field           | Definition
-----------|-----------------|-------------
Momentum   | ret_6m          | 6-month total return
Volatility | vol_60d         | Std dev of daily returns
Value      | earnings_yield  | 1 / P E (use Yahoo Finance P E)
Quality    | roe             | Return on Equity
Liquidity  | dollar_vol      | avg(close × volume) 60 days

-----------------------------------------------------------------
5️⃣ Key tables
-----------------------------------------------------------------
Table             | Purpose
------------------|----------
index_definitions | Rules JSON for each index
signals           | Raw and derived factors
weights_log       | Per-rebalance weights, caps, scores
index_history     | Daily level and return
explanations      | Short narratives per rebalance

-----------------------------------------------------------------
6️⃣ Process flow
-----------------------------------------------------------------
1. Load signals for cutoff date (as-of).
2. Rank & select according to rules JSON.
3. Assign weights (equal / score / inv-vol).
4. Apply caps / normalize.
5. Compute daily returns & levels:
   r_t = Σ w_i · r_{i,t}
   level_t = level_{t−1}(1 + r_t)
6. Write to DB (weights_log, index_history).
7. Generate narrative:
   “Index rose 1.2% as TSLA (+4.5%) and NVDA (+3.1%) led gains.”

-----------------------------------------------------------------
7️⃣ Outputs & validation
-----------------------------------------------------------------
- Sum(weights) ≈ 1.0
- Rebalance dates logged
- Consecutive index dates (no gaps)
- Narrative generated per rebalance
- Benchmark comparison vs SPY & VTI

-----------------------------------------------------------------
8️⃣ Deliverables
-----------------------------------------------------------------
- 3–5 working indices
- Data dictionary for signals & weights
- Rebalance and performance dashboards
- “Explain this index” summary API


=================================================================
🚀 PHASE 2 — NICHE, FUNDAMENTAL, AND NARRATIVE EXPANSION
=================================================================
Goal: Layer in real fundamentals, advanced weight logic, and narrative/AI explainability.

-----------------------------------------------------------------
1️⃣ New data sources & feeds
-----------------------------------------------------------------
Purpose             | Source                     | Notes
--------------------|-----------------------------|-------
Fundamentals        | FinancialModelingPrep API   | Key ratios, income, balance, cashflow
Sector / industry   | FMP or Yahoo Profile        | Needed for caps & diversification
Macro benchmarks    | FRED API                    | Risk-free rate, CPI, Treasury
Optional upgrade    | Sharadar SF1 (Nasdaq Data Link) | Point-in-time fundamentals

-----------------------------------------------------------------
2️⃣ Enhanced signals
-----------------------------------------------------------------
Theme     | Examples
----------|-----------
Value     | P E, P B, EV / EBITDA, FCF Yield
Quality   | ROE, ROA, Gross/Operating Margin, Leverage
Growth    | EPS CAGR, Sales CAGR
Risk      | β, Max Drawdown, Downside σ
Size      | log(Market Cap)

-----------------------------------------------------------------
3️⃣ Advanced weighting schemes
-----------------------------------------------------------------
Type               | Description
-------------------|-------------
Inverse Volatility | w_i ∝ 1/σ_i
Score Weighting    | w_i ∝ max(0, score_i)
Capped Weighting   | Clamp to 10 % per ticker
Sector Capped      | ≤ 35 % sector weight

Normalize after constraints.

-----------------------------------------------------------------
4️⃣ Narrative / AI layer
-----------------------------------------------------------------
Rule → Language bridge:
- “Top 25 by Earnings Yield” → “This index targets value stocks trading cheap to earnings.”
- “Equal weight” → “Each constituent contributes 4 % to the index.”

AI augmentation (later):
- Fine-tuned LLM summarizes performance drivers each rebalance.
  Input: weights_log + index_history; Output: human-readable report.

-----------------------------------------------------------------
5️⃣ Transparency / audit features
-----------------------------------------------------------------
- Public JSON rulebook per index
- Versioned “as-of” signals & weights
- Explainability API (GET /index/<slug>/explain?date=YYYY-MM-DD)
- Optional “replay mode”: re-run past rebalances for audit

-----------------------------------------------------------------
6️⃣ Milestones
-----------------------------------------------------------------
1. Integrate FMP fundamentals (Phase 1 logic unchanged)
2. Compute new signals → Value/Quality indices
3. Add advanced weighting methods
4. Launch narrative API (+ LLM summary)
5. Publish transparency dashboard (index rules + latest holdings)

-----------------------------------------------------------------
7️⃣ End state
-----------------------------------------------------------------
- Library of general + niche indices
- Full audit trail from price to narrative
- Extensible ETL that can ingest any fundamentals source
- Foundation for domain-specific indices (healthcare, sustainability, etc.)
